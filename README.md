# AI Milestone Radar

Interaktiver, quellenbasierter Meilensteinradar für **AI Unlocked Advanced** von edutrainment.

Der Radar ordnet wichtige KI-Entwicklungen seit Mitte 2025 ein und übersetzt sie in konkrete Fragen und kleine Tests für den Arbeitsalltag.

## Nutzung

Die Anwendung besteht aus einer statischen HTML-Seite und benötigt keine Installation. `index.html` kann direkt im Browser geöffnet oder über GitHub Pages bereitgestellt werden.
